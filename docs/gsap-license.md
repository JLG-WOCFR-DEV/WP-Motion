# Licence GSAP

Le plugin est GPL-2.0-or-later. **GSAP n’est pas bundlé**.

Quand une scène `split-text`, `pin` ou `parallax` est présente dans le HTML publié, le front peut charger GSAP 3 depuis jsDelivr (`gsap.min.js`, `ScrollTrigger.min.js`, `SplitText.min.js`) sous la [Standard License GSAP / Webflow](https://gsap.com/community/standard-license/).

## Ce plugin n’est pas

- Un builder visuel de type Webflow Interactions (pas de timeline, pas de keyframes libres)
- Un outil pour créer des animations arbitraires sans code

C’est un jeu de **presets + paramètres** (réglages wp-admin + attributs de blocs Gutenberg).
